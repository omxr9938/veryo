# Veryo – Ernährungstagebuch (Web-App)

Einzelne Datei `index.html`, keine Installation nötig. Daten bleiben lokal im Browser.

- Kalorien, Makros, Vitamine & Mineralstoffe tracken (manuell, Suche, Barcode-Scan via Open Food Facts)
- KI-Coach: lokale Hinweise + optional Claude (eigener API-Key im Profil)
- Aufs Handy: Seite per HTTPS öffnen (z. B. GitHub Pages), dann „Zum Home-Bildschirm“.
